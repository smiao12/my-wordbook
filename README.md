# 我的单词本

一个按考研年份整理真题生词、支持三端同步的 PWA 单词本应用。

## 功能

- **按年份整理** — 单词按考研真题年份分组（如 2025、2024…），未分类单独归组
- **三端同步** — 登录账号后，手机 / 平板 / 电脑数据自动同步
- **本地优先** — 未登录也能用，数据存本地；登录后自动上传云端
- **语音朗读** — 点击喇叭图标播放单词读音
- **例句关联** — 记录真题原句，加深记忆
- **批量导入** — 文本 / JSON 格式批量导入，统一归入指定年份
- **数据导出** — 导出 PDF（打印为PDF）或 JSON 备份
- **作文功能句** — 考研作文句型整理（待开发）
- **多彩主题** — 6 种主题可选

## 快速开始

1. 用浏览器打开网页
2. 直接开始使用（本地模式），或登录账号开启三端同步

## 三端同步

登录后数据存云端（Supabase），换设备登录同一账号即可同步：

1. 右上角设置 → 账号 → 登录 / 注册
2. 输入邮箱 + 密码（首次点「注册新账号」）
3. 之后任意设备登录同一账号，单词自动同步

> 未登录时数据保存在浏览器本地（IndexedDB），不会丢失但不同步。

## 添加到桌面

### Android (Chrome)
1. 打开网页 → 菜单（⋮）→「添加到主屏幕」

### iPad (Safari)
1. 打开网页 → 分享按钮 →「添加到主屏幕」

## 使用技巧

### 录入单词
1. 点击右下角 ➕ 按钮
2. 输入英文单词、中文释义
3. 填写年份（如 2025，留空归入「未分类」）
4. 补充音标、例句（可选）
5. 保存

### 批量导入格式

**文本导入**（每行一个）：
```
abandon | 放弃；抛弃 | She abandoned her car.
apple | 苹果
banana
```

导入时在上方「归入年份」填年份，整批单词统一归入该年份。

**JSON 导入**：
```json
[
  {"word": "abandon", "meaning": "放弃；抛弃", "example": "She abandoned her car."},
  {"word": "apple", "meaning": "苹果"}
]
```

### 导出备份

- 设置 → 导出单词（PDF）：打印为 PDF
- 设置 → 导出单词（JSON）：下载备份文件

## 技术栈

- 前端：HTML5 + CSS3 + Vanilla JS（PWA）
- 数据存储：Supabase（云端）+ IndexedDB（本地缓存）
- 语音：Web Speech API（浏览器原生）
